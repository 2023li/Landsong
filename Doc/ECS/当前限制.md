# 当前限制

以下是当前产品边界和已知风险。本轮架构重构是否完成及实际运行验证结果见 [当前修复与验收记录](../ECS/问题修复记录20260917.md)，不以旧基准的 PASS 代替当前验收。

## 内容与制作

- 模型、皮肤、角色动画、肖像、图标、粒子、音效和 UI 仍有占位。四个 Music 配乐槽为空，需提供正式配乐。
- 英文并未覆盖全部详细文案和复杂动态格式。缺译回退中文；缺语义模板的拼接文案需要程序补模板，不能仅靠美术或翻译解决。
- 三名人才、六种基因、两项政策、一个基础兵种及泰坦等为可编辑基础内容；未包含完整英雄主动技能或更多平安小游戏。
- 肖像当前使用程序生成部件，Release 门禁会拒绝当前配置；必须按 PortraitConfig 统一尺寸接入完整美术部件并关闭 Placeholders；SkinDetail 多选数据和渲染保留扩展位置，当前占位及捏脸没有皮肤细节多选或独立临时 Effect 流程。
- QM007 是禁用草稿，不属于可玩的主线。

## 验证边界

- 当前正式游戏地图为 Map_Map01；地图制作验证使用临时副本，特殊玩法条件使用隔离 World 夹具。当前结果不等于所有内容组合、长期平衡或 Release 美术已验收。
- 已有 TWC 增量导入、占地/初始建筑校验，不代表任意复杂 TWC 重生成、所有高度/道路/入口组合都已人工验收。
- 未完成所有定义、食谱、岗位、供给、空间效果、科技、任务、政治的全组合与长局平衡验证。空间效果按当前规则支持的目标/半径/叠加执行，不可假设任意标签、分组或格过滤已有执行器。
- 基础 UGUI 与有限分辨率测试不等于全部尺寸、缩放、真实触屏设备或手柄体验验收。
- 科技/任务配置可以编辑规则与关系，不提供完整拖线建边工具。列表/家谱并非无限规模虚拟化。
- ECS 快照当前为 v37，ES3 王朝封装为 v4；v33/v34/v35/v36 的字段读取只用于同内容指纹的迁移，目录变化仍可能拒绝旧存档。领域快照保留字段覆盖、损坏恢复与往返测试。
- RootState 覆盖检查可以拒绝未登记的 Landsong 根组件，字段协议检查可以发现新增字段遗漏；它们不能代替每个新增领域状态的业务合法性与故障回滚用例。

## 性能与资源

WorldPresentation 已缓存模型选择与静态 Transform，清理容器复用；每帧仍读取候选实体以更新运动和动画。A* Pro RVO 接管动态单位避让，当前 ABPath 在重新规划时同步完成，大量同帧重规划仍可能造成主线程峰值。经济事务、部分遍历和接战位也仍有主线程工作；尚未对超大军团作帧率承诺。

本轮 [20–200 单位接战位微基准](性能基线/接战位预约20260917.md) 与完整扫描参照的位置结果一致；测量时当前线程托管分配为 0 B/次。该结果不包含原生内存、Job 等待与渲染，也不代表 WorldPresentation 的整帧分配检查已完成。

N08 已按 P3 建立 [实际查询性能基线](性能基线/README.md)：在本机 Editor 的 10,000 实体隔离夹具中，`Sim.Find` 末尾命中 p50 为 1.309 ms/次，`OrderedEntities<Building>` 完整排序为 37.064 ms/次。当前线程 managed 分配为零不代表原生分配为零；报告中的原生实体数组载荷仅为源码推导下限。本次尚无 Player 的真实调用频率、混合实体分布和帧预算证据，因此未引入索引，也不据此宣称优化达标或推断整机帧率。复现入口、原始 CSV/JSON 与环境限制均随基线保存。

独立程序退出仍可能报告 ComputeBuffer 自动回收及引擎 MemoryLeaks / FontEngine 诊断，尚未完成归因或修复。短流程反复加载中字体/图集数量稳定，只能说明该测试未观察到逐次累积，不能据此宣称没有泄漏。

外部插件存在旧 API 警告；项目清理不擅自升级、移除或修改第三方包。当前验证结果见 [验证工作流](验证工作流.md)。

# 夜晚模板与难度配置

## 配置入口

- `Assets/Landsong/ECSContent/Catalogs/Source/NightEventCatalog.asset` 引用所有夜晚 SO。每晚从满足条件的定义中抽取一个；`Guaranteed` 夜晚按优先级覆盖普通抽取。
- `Assets/Landsong/ECSContent/Definitions/Night/` 存放平安夜、普通战斗夜和首领之夜的样例。各 SO 配置回合、天气、前置条件、字幕和完整波次模板。需要雨夜时将 `AllowedWeather` 改为雨天相关选项。
- `Assets/Landsong/ECSContent/Presentation/Night/LandsongNightCaptionEffects.asset` 只配置字幕延迟和动画。所有夜晚文案均在对应夜晚 SO 中。
- 夜晚目录的 Inspector 提供“生成并打印本夜波次到 Console”按钮。输入回合、玩家战力、天气和样本种子后可预览实际数量与时间。
- `Assets/Landsong/ECSContent/World/GameContentSet.asset` 的 `Night` 设置包含难度曲线参数。

## 数量和时间

每个模板波次手动配置出兵秒数和正负波动范围。规划夜晚时抽取一次波动时间，同一晚及重试期间保持固定。时间指正式入夜后的实际出兵时间；预警会提前显示。所有波次结束且敌人清空后，沿用胜利流程允许玩家跳过剩余夜晚。

波次数量由模板固定，每波允许多种敌人。普通敌人数量为 `floor(数量权重 × 难度系数)`；固定数量条目不乘系数，首领必须固定为 1。结果为 0 的条目不出兵，整波为空时跳过。敌人血量和伤害不随夜晚难度放大。

## 难度系数与战力

系数范围为 1 到 10。先按回合计算基础值 `1 + (回合 - 1) × 每回合难度增长`，再用玩家战力与同回合预期战力的比例修正；修正倍率限制在 0.75 到 1.25，最终系数限制在 1 到 10。参数 `DifficultyPerTurn`、`ExpectedPowerAtTurnOne`、`ExpectedPowerPerTurn`、`PlayerPowerSensitivity` 均可在内容集合中调整。

玩家战力是可参战士兵、已招募且满足条件的英雄、运营中的己方建筑各自 `NightPower` 的总和。该值直接配置在士兵、英雄和建筑定义中，不读取力量、敏捷、智力、血量或装备计算。敌人定义也有 `NightPower`，用于显示本夜总威胁，不改变个体属性。

首领之夜没有后续返回事件。满足条件时按 SO 直接出现；未满足条件时不出现。旧快照版本已弃用，当前为 v39。

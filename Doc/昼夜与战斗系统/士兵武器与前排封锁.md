# 士兵武器与前排封锁

更新日期：2026-09-25。本页描述本轮已接入的武器槽原型、攻击方式和前排拦截规则。

## 玩家操作

白天打开士兵详情，点击“武器”按钮依次切换 **木棒（空槽）→ 短剑 → 短弓 → 木棒**。暂停、情报模式、存档检查点进行中、士兵死亡或非白天时不能更改。按钮文字和详情中的攻击类型、伤害、射程随实际状态刷新。命令通过 `EquipSoldierWeaponRequest` 交给 ECS 执行；界面不直接修改士兵数据。

目前这个槽位是战斗原型选择器。短剑使用现有罗马剑模型，木棒和短弓是可替换的右手灰盒；三种选择暂不消耗库存物品，也没有耐久、换装费用和头盔/护甲数值。头盔、护甲按钮仍是占位。正式物品接入时应把槽位与 `ItemDefinition`、库存转移和交易校验关联，保留本页的战斗判定入口。

## 攻击规则

| 武器槽 | 基础伤害系数 | 攻击距离 | 结算 |
| --- | ---: | ---: | --- |
| 空槽：木棒 | 0.75 | 1.15 | 近战直接提交伤害请求，不创建弹体 |
| 短剑 | 1.00 | 1.15 | 近战直接提交伤害请求，不创建弹体 |
| 短弓 | 0.85 | 至少 4.5 | 发射追踪弹体，速度至少 10 |

基础伤害先按兵种定义、科技、人才及个人等级计算，再乘武器系数。弓保留更高的已配置射程和弹速；近战清除范围爆炸半径。目标半径和战斗系统原有的 0.2 距离容差仍参与命中判断。武器选择在黄昏配置出战单位时写入 `Combatant`，夜间不能换装。无武器默认使用木棒，因此民兵不再以原定义的 4.5 射程发射弹体。

木棒/短剑沿用近战挥击动作；短弓使用 `Shooting Arrow` 派生的 `RangedAttack` 动作和 `Shoot` 触发器。拔出武器和收回武器仍在双臂层播放，行走留在 Base 层；空槽拔出木棒，近战装备用剑，远程装备用弓。模型只负责表现，伤害由 ECS 在攻击时点结算。

## 前排封锁

存活、已出战的我方士兵若当前使用木棒或短剑，就成为近战拦截者。敌人重新感知目标时，先查找距离自己不超过 `max(2.4, 敌人攻击距离 + 0.5)` 的近战士兵；有多个时选最近者，同距离按稳定身份 ID 选择。该目标覆盖敌人对高威胁后排的普通选取，也覆盖狼的“最近士兵”特殊选取。敌人随后按现有寻路、站位与攻击流程接近并攻击拦截者。弓兵不提供拦截。

这是目标选择层面的封锁，不修改地图通行性，也不让士兵成为永久不可穿越的障碍。没有存活的近战拦截者、距离超出保护范围、前排阵亡或归营时，敌人立即按原规则重新选目标。远程敌人在前排进入其警戒半径后同样会转火前排；范围攻击和已经发射的弹体仍按其原有命中规则结算。

## 状态与验证

选择保存在 `Soldier.Weapon`，ECS 快照升级到 **v37**；读取 v33～v36 时，旧士兵的武器槽设为空，按木棒近战运行。存档恢复后，战斗属性在夜晚准备时重建，武器灰盒随表现实体创建与释放，不进入持久快照。非法武器枚举值在命令和快照校验阶段拒绝。

编辑器验证覆盖白天换装请求、武器状态往返、空槽近战与弓箭远程数值、近战前排保护高威胁后排、木棒/短弓表现挂点、双臂层与射击动作。对应入口为 **Landsong → ECS → Verification → Combat** 和 **Landsong → 动画 → 验证罗马士兵接入**；自动化动作为 `VerifyWeaponCombat`、`VerifySoldierAnimations`。

本轮实际验证结果：`VerifyWeaponCombat` 48 项、`VerifySoldierAnimations` 94 项、`VerifyPersistenceContracts` 的协议 241 项与存档服务 52 项、`VerifyGameUiInputPolicy` 28 项均通过。全局 `VerifyUiConfiguration` 另有 15 项未通过，涉及 UI 文本与点击音效绑定、运行时组件查找及检查器中文标签；这些项目需要单独排查。尚未在图形 Play 模式逐帧检查挥击接触、弓箭持握和近战拥挤站位。

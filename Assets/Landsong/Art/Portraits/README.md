# 肖像美术部件

使用 Unity 菜单 Landsong → ECS → Portraits → Import parts 打开“肖像部件导入”。

- 窗口从项目 PortraitConfig 读取尺寸（当前默认 64×64，可配置为 32×32），禁止自动缩放或裁切。
- 选择部件类别与稳定标识，勾选男用/女用，可复选，不能都不选。
- 点击“添加图层”按需提供 PNG，可随时移除图层。各程序层均非必填，逻辑部件至少提供一张有效 PNG；发型可仅前发、仅后发或同时包含两层，不必补全透明图片。
- 一个逻辑部件拆成多个程序层时，可继续添加同类别的其他层；层名不能重复，各层使用独立源文件。未填写 PNG 的行不参与导入。
- 导入器复制源 PNG 到 Parts/<类别>/<稳定标识>/<图层>.png，配置导入参数并登记 Parts。只复制图片到文件夹不会自动登记。
- PNG 使用统一完整画布。需染色的部分采用灰度；固定颜色图层用 None。
- 程序占位和正式素材可以共同使用；正式库备齐后再考虑关闭占位。
- 不要随意改名或删除已登记部件，稳定 ID 会写入人物存档。

详细规则、参数与工作流见项目根目录 Document/肖像系统初稿.md。

# 任务与邀约

任务定义位于 ECSContent/Definitions/Quest，编辑菜单 Landsong/ECS/任务配置与校验。任务、要求进度、追踪和来源槽都是 ECS 数据，不依赖任务运行 Prefab。

## 任务操作

任务窗口固定为两列：左侧已接受任务，右侧建筑邀约。每个灰色框是一格槽位；点击标题箭头原地展开/收起描述、逐项要求、前后置、奖励及失败后果，不再打开第三列详情。右侧贸易/建设/民生/探索使用独立 Toggle 多选，只显示勾选类型，全不勾选时为空；来源筛选可以单独取消。空邀约槽显示刷新回合，停运显示暂停原因，保留付费立即邀约入口。窗口关闭按钮固定在标题栏，滚动时仍可使用。

两侧均显示来源建筑名称和三维坐标。左侧槽位标题显示承接容器来源，展开内容另列原始邀约来源；两者可能不同。接受邀约优先使用其来源建筑的空承接槽，否则按稳定建筑 ID / 槽号选择其他空槽；任务连同展开状态移至左侧，右侧原邀约槽开始冷却。绑定后不因刷新、领奖排序或存档恢复自动换容器。

主线自动接受，不提供主动放弃入口。皇宫提供 4 个通用承接槽和 1 个贸易邀约槽；主线与一般任务使用相同的真实承接槽，不再有专用槽或负数槽号。首次出现的主线在没有空槽时等待，不创建任务、不开始期限计时；出现空槽后自动接受。皇宫失效由现有终局流程处理。

所有分步任务（含主线及一般任务）成功领取当前步骤奖励后，直接后续沿用上一任务的 Container / ContainerSlot 和原始 Source / Slot，在同一次命令内完成交接，其他空槽或满槽都不会使它换位。下一步拥有独立进度与期限，不重启原邀约冷却、不要求再次签约；整条任务链最后一步领奖后，原槽才释放给一般任务。额外前置未满足时，后续步骤仍占原槽并显示“等待前置”，期间不计时、不累计进度或接受提交，条件满足后开始。当前内容是线性六步主线；若定义有分支，同槽优先衔接前置已满足者，再按物品奖励价值降序、目录顺序选择一项，其他主线分支按普通主线发现规则等待空槽。

普通任务标题旁 X 弹出“确认放弃任务？”；已完成任务改为绿色卡片和 ✓ 领奖按钮。完成后仍占槽，整份奖励成功领取后衔接下一步，任务链结束才释放；取消确认、奖励放不下均保留任务和槽位。夜晚只能查看。

每张已接受任务卡标题旁提供追踪 Toggle（空槽和未签邀约不显示）：勾选切换到该任务，其他卡自动取消勾选；取消当前勾选后保持不追踪，定期刷新不会重新勾选；快速勾选后取消按命令顺序处理，另一张卡迟到的取消不会清掉新目标。可通过“自动追踪”恢复选择。

HUD 中已完成的追踪任务显示“领取奖励”，直接提交领奖命令，不先打开任务面板。成功领取当前追踪任务后，优先追踪继承原槽的新步骤（包括等待额外前置的步骤）；没有本次衔接步骤时再选择已接受的直接后续任务，有多个时选物品奖励价值最高者。没有可追踪的后续时，从承接槽里的进行中/待领奖任务中选价值最高者；没有任务则 HUD 留空。并列按稳定任务 ID 升序。未签邀约不参与自动追踪；自动衔接不绕过步骤的前置条件，也不从邀约面板签入其他任务。领奖失败保留原追踪；领取另一张未追踪任务的奖励不会抢走当前手动选择，明确取消追踪也不会被其他任务领奖重启。自动选择结果及手动取消沿用 QuestTracking 持久状态，刷新与读档保留当前有效目标。

任务价值 = Σ（烘焙后物品奖励数量 × 物品定义 Value 单价），与市场的物品单价口径一致。物品倍率已在烘焙时计算，此处不再乘第二次；不扣提交/失败成本，蓝图、Buff、功能许可不折算。邀约按价值降序跨来源排序，同价值按稳定任务 ID，空邀约槽排在任务之后；排序不改变持久来源/槽号。要求可持有、逐项提交、建造、种植、研究、回合或实际镜头操作。持有不扣物，提交累计；完成状态保持，领奖后衔接后续步骤；任务链结束后释放承接名额。

提交选择要求和整数数量，确认只扣该项正常库存；旧确认失效、取消、重复点击不重复扣费。签约、拒绝、付费邀约、面板内领奖、放弃都有确认；HUD 的领取奖励按钮直接领取。整份奖励放不下保留待领奖，不半发。失败物品按同类汇总，最多扣正常库存已有量，不扣待存放、不重复处罚。夜晚只读。

白天命令成功后即时评估任务，结算先检查当次生产/研究完成，再检查到期。镜头在边界未实际移动/缩放不计完成。

## 当前主线与内容

六条有效主线依次是：移动/缩放镜头 → 收集建材 → 建造 3 农田 → 种植 3 农田 → 完工 3 居民房 → 选择实际当前研究。主线 1/2/5 分别授予 Inventory / Building / Technology，Expedition 由“阵列作战”科技授予。

目录有 11 个任务资产：6 主线、4 随机、1 禁用草稿 QM007。草稿不能自动完成或领奖。

随机木材要求 10 原木；石材基础 5 × 倍率 2；泥土基础 10 × 倍率 3；探索补给基础 5 原木 + 3 石头。物品奖励和失败惩罚也统一乘模板倍率，不只缩放要求。

## 来源与抽取

市场强度来自累计历史流转，远征所强度来自等级与经验。QuestGeneration 设置四档抽取权重，乘任务自身 QuestWeight；**来源强度只影响概率，不再次缩放物品数量**。

带任务前置的普通任务作为后续步骤，不进入独立邀约抽取池；只有任务链首步参与邀约，科技前置仍按原规则过滤。

来源身份为建筑 ID + 类型，槽位稳定；冷却到期每次只补一个空槽。自动邀约免费但不自动接受，满槽不反复抽签；付费先检查候选和整份费用，失败不扣费、不耗随机数。

市场缺工/维护失败/未运营，或远征所在途时暂停补充。未签邀约在停运时保留，拆除来源时移除；邀约槽缩容删除超额未签邀约。已接受任务使用独立持久的 Container / ContainerSlot，原邀约来源拆除只有在同时为承接容器时才会导致已签任务失去。

承接容器必须正常运营、维护满足且岗位满员（无岗位建筑不需工人）。停工、缺工、维护失败、拆除/摧毁或缩容使其槽位失效时，所绑定任务（包括等待前置及已完成待领奖）一并失去，按普通放弃扣除失败惩罚，不退还提交物资、不发奖励，不迁移到其他空槽。重复检查不重复扣罚；原来的“总容量不足阻止入夜并要求手动弃任务”流程不再作为正常处理方式。结算预演中的任务丢失和处罚随事务一起提交或回滚。

新邀约更新消息，可点定位来源，不自动弹窗。

## 制作字段

- Flags：0 随机、1 主线，另加 2 禁用草稿。
- 每个要求必须有唯一稳定 Rule.Key；后缀也是创作身份，不能随排序重新生成。
- QuestIntensity 0～3；QuestWeight 为抽签权重；ItemQuantityScale 在 Baking 中对基础物品要求、奖励和失败惩罚缩放一次，蓝图/Buff/许可不缩放。
- GameCatalog.QuestGeneration 定义强度换算和四档权重；建筑 QuestSource 定义来源条件/容量/冷却。
- Baking 拒绝空要求、重复 Key、非法目标、期限、前置循环和非法草稿引用。支持 Undo、定位与保存，不提供拖线建边编辑器。

存档按稳定要求 Key 对应进度；只有规则未变的换序可重映射，不以数组下标推断进度。

承接容器及槽号随快照 v22 保存。恢复校验真实容器、槽号上界和重复占位；旧版快照按版本门禁拒绝；本次格式仍为 v22，但皇宫容量调整改变内容签名，调整前的存档不兼容，需要新开王朝，原存档文件不修改。

# 表现与语言制作

模型、粒子、音源、生成画像贴图和文本不参与玩法快照；人物肖像 DNA 参与。先修改资源绑定，缺失时使用明确占位或中文回退；不要用动画事件修改 ECS 状态。

## 配置入口

统一资源：`Assets/Landsong/ECSContent/Resources/LandsongPresentation.asset`。

占位素材：`Assets/Landsong/ECSContent/Presentation/`，含 militia / titan / raider / invader / boss 的 Cube 表现 Prefab、材质、共用 `Actor.controller`、11种状态动画和 `CueBurst.prefab`。

这是**纯表现 Prefab**，不是实体的 Authoring Prefab。正式静态建筑仍使用已有 `ECSContent/Prefabs` 中的分级/皮肤/建造/荒废槽位，不需要改变静态槽位配置。未提供动态绑定时继续显示原 ECS 模型。

### 建筑/角色的动态模型

在资源的 `Models` 增加一项：

- `Definition`：内容稳定 ID，例如 `b仓库`、`militia`，不是玩家可修改的显示名。
- `Stage / Level / Skin`：阶段、起始等级、皮肤 ID。先匹配同皮肤和不超过当前等级的条目，优先精确阶段，然后回退 Operational；同优先级取最高适用等级。不匹配则保留原 ECS 外观。
- `Prefab / Offset / Scale`：纯表现 Prefab、世界偏移与缩放。实例根在 Game 场景的独立 `ECS World Presentation` 下，不在 Canvas 下，不随界面缩放。

绑定生效时只接管该实体的外观，原 ECS 外观临时隐藏；删除绑定、卸载或恢复后归还外观所有权。不改变碰撞、占地、导航、生命、选中或人口。

Prefab 可以放 Transform、MeshFilter、Renderer、Animator、ParticleSystem、Light、LODGroup、`PresentationActor`。不允许 Camera、AudioListener、Collider、Rigidbody、Gameplay/Authoring 脚本；非法绑定拒绝使用并提示，原 ECS 模型继续显示。模型尺寸和地面位置由美术自行制作。

`PresentationActor` 可配置：

- Animator 参数 `Pose`（int）、`Moving`（bool）、`Speed`（float）；名称与类型同时匹配才写入。`Pose` 顺序为 Idle、Moving、Working、Construction、Repairing、Stopped、Ruined、Dead、Celebration、Guard、Rescue。
- Cue 同名 Trigger，例如 Hit / Harvest / Bell / HeroWake。正式动画状态机可消费这些触发；占位控制器提供11种 Pose 的可运行示例。
- `WorkingParticles / WorkingLights`：施工、修复、正常工作的粒子与灯光。停工/荒废时关闭；粒子在暂停时冻结。
- `MovingPart / RotationPerSecond / BobHeight`：简单旋转和移动/庆祝起伏占位。减少动态效果会停止这些连续效果和粒子；不要给同一属性同时配置动画曲线和旋转脚本。

Animator 禁用 Root Motion。动画事件不得修改玩法、发奖励或推进阶段；ECS 才是权威。实际移动仍由 ECS/DBP 决定，Animator 只读取位置差、生命、施工和夜晚收尾状态。已经出现在画面中的单位死亡后，表现实例保留1秒倒地窗口（暂停时冻结），不延迟玩法死亡或奖励；未唤醒/从未显示的英雄不会因初始零生命显示“幽灵尸体”。

### 音频与效果

`PresentationRuntime` 是应用级唯一表现服务，创建2个循环音源（Music/Ambient）与16个复用 Cue 音源；**不创建监听器**。四场景仍使用各自相机的唯一 Listener。

资源字段：MenuMusic、DayMusic、NightMusic、CombatMusic、DayAmbient、NightAmbient、FadeSeconds。切换先淡出旧循环，再切换并淡入；不是两个 BGM 同时交叉叠加。Boss 属于战斗音乐。场景切换清除短音效和冷却，循环按场景/阶段选择。

已有自然环境音和木质 UI 音效已回接。部分战斗/建造声音暂时复用点击音作为触发占位，**四个 Music 配乐槽目前留空**，正式配乐需单独配置。功能测试使用自行创建且测试后销毁的音频片段验证循环通路；正式配乐与最终音效仍由用户提供。

每个 `Cues` 条目配置语义 Id、Clip、Bus、Volume、Cooldown、Concurrency，以及可选 Effect/Lifetime。现有桥覆盖 UI 点击/拒绝、建造/修复/完工/收获、伤害/死亡/荒废、警铃/英雄唤醒、平安访客/抓获、掉落、情报查看、收尾和战报。真实伤害在减伤/阵营/保护校验通过并扣除生命后发布Damage；普通死亡仅首次发布；抓获在真正完成拦截后发布。瞬时事件保存发生位置，目标随后隐藏/销毁也可播放效果。复用统一事件消费者，不抢走 CheckpointSystem 的存取档请求，不提前公布盗窃物品或高档情报。

Master 只施加在 Listener，Music/Effects/Ambient 在各自音源上施加，UI 跟随 Effects；静音不修改原音量值。暂停冻结世界短音效、模型动画与粒子，UI音效和背景循环保持可用。粒子最多32个，按世界暂停时钟释放，卸载/节点重建由场景所有者统一清理。

### 王室、人才与政策

王室左侧使用可双向滚动/缩放的横向世代灰带、蓝色家庭框及白色双亲卡，右侧显示选中人物详情。当前君王有皇冠占位标记，登基子代使用金色亲子线，逝者置灰，历史世代保留。人才页复用画像卡片，政策页按 Level 分列；操作均提交原 ECS 命令。

肖像使用 `ECSContent/PortraitConfig.asset` 的程序占位部件及色盘，正式 PNG 通过 `Landsong → ECS → Portraits → Import parts` 导入，自动保存到 `Art/Portraits/Parts/<类别>/<标识>/` 并登记；窗口检查项目原始尺寸、男/女复选及图层合法性，程序层按需添加或移除，不强制前后发配套，一个逻辑部件至少提供一张有效 PNG。程序占位可与已导入部件并用。完整流程见 [肖像规格](../肖像系统初稿.md)。`Portraits` 的非零 Person 稳定 ID、Definition 默认和 DefaultPortrait 仍可提供完整 Sprite 覆盖；完成“丽质”捏脸后优先显示模块化结果。覆盖图由资源系统持有，不由肖像缓存销毁。完整覆盖图保持原样，程序衰老作用于模块化结果；遗传始终读取持久基础 DNA。

肖像 DNA 和士兵个人生命周期参与存档；生成的 Sprite、Texture、音效和 UI 本身不参与。当前肖像为程序生成的功能占位，正式部件、动画、音效及界面美术仍由用户制作。

## 本地化制作

内置 `zh-Hans / en`，在主菜单或暂停设置中点“语言 / Language”切换，再应用。外部包扫描在同一页，诊断直接显示。语言变化只刷新 TMP 渲染文本，原始按钮路由字符串、玩家编辑框内容和历史快照不改写；不复制字体或图集。

保留并导入`Objects/本地化/Tables` 的 UI、Content、Gameplay 中英条目，补 ECS 固定入口和动态格式 Key，并为现有185项内容提供稳定名称/说明 Key；当前运行表条目数量以 Sync language entries 输出为准。资源 `Text` 是当前运行表；StringTable 是追加条目时的素材来源。英文按钮启用限定范围的自动字号适配，切回中文恢复原样式；HUD使用显式语义格式并保留王朝自定义名。

编辑器菜单 `Landsong/ECS/Presentation`：

1. **Sync language entries (preserve edits)**：追加缺失的原表/ECS/内容条目，保留已有翻译与美术配置。已有条目日常直接编辑当前资源，不以同步覆盖修改。
2. **Export language pack template**：输出 `Library/LandsongEcs/language-template.csv`，以最新模板制作翻译，不猜测 Key。

新代码优先调用 `PresentationText.Get("Gameplay/语义Key", "中文 {0}", 参数)`；现有 UI 由 TMP 预处理器按固定文本/格式模板回接语义 Key。动态模板先匹配更具体的文本，不生成路径哈希或带当次数值的 Key。无法匹配、缺翻译或参数不兼容时保留中文；不会把未知文本删掉。

**这不是全量英文翻译完成声明。** 现有表之外的详细玩法文案、历史快照和新增内容可能仍为中文；需要继续为对应语义 Key 补译/补格式模板。人物/建筑自定义名字不做自动翻译。当前预处理兼容桥不替代所有复杂拼接文本的一次性重写。

外部包位于 `Application.persistentDataPath/ExternalLanguagePacks/<目录>/`，由 `manifest.json` 和 `strings.csv` 组成。格式沿用 V1，当前 `targetKeysetVersion=5`：

```json
{"schemaVersion":1,"targetKeysetVersion":5,"packId":"community.example","displayName":"Example","localeCode":"en","fallbackLocaleCode":"en"}
```

```csv
Table,Key,Text
UI,ui.ecs.pause,Pause
Gameplay,gameplay.ecs.turn,Turn {0}
```

仅文本：不加载字体、图片、脚本、DLL、Prefab、远程URL或任意文件路径。Table仅 UI / Content / Gameplay；参数为.NET数字位置格式 `{0}`～`{15}`，允许顺序调整/数字格式，但参数集合必须一致。不是任意 SmartFormat 表达式执行器。去除外部 TMP 标签，缺字仍受内置字体覆盖限制。

严格UTF-8（允许BOM）、标准CSV引号/换行；manifest≤16KiB、CSV≤2MiB、最多20000行、单条≤8192字符；最多扫描32个目录。拒绝符号链接/重解析目录文件、重复Key、非法参数、内置保留包ID和非法清单。重复packId禁用两者；无效的当前包更新保留上次成功文本并显示诊断。缺项按声明的内置语言回退，再退中文；静态空文本可刻意留空。

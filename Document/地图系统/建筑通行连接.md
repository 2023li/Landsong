# 桥梁、阶梯与多地表通行

当前基准：MapContentAuthoring 烘焙、建筑生命周期与 A* Pro 导航适配共用同一份显式分层通行数据。TWC 负责地形绘制与显示；模型、碰撞体、倒角或缝隙不决定连接是否存在。

## 高度与地表

- 地表保存整数高度等级，世界高度 = 等级 × 地图的高度单位。新地图可设单位为 1；0、1、2 是合法等级，2.781 不能作为等级或绕过单位约束的地表高度。
- 阶梯两端的等级是整数，单位行进中的高度沿逻辑坡面连续变化，不会逐级瞬移。
- 主逻辑地表保留建造、地形和通行属性。同一 XZ 需要另一条独立路线时，在场景的“导航地表与连接”中添加额外地表，绑定 TWC Blueprint GUID、稳定正整数地表 ID 和整数等级。额外地表只参与导航，不提供另一套建筑堆叠位置。
- 主地表使用它在逻辑地图中烘焙的 Surface ID，通常为 0；额外地表 ID 必须唯一且为正整数。同格同高度的重复地表被拒绝。
- 邻格只在地表 ID、等级和实际高度一致时自动相连。跨高差、跨不同地表必须声明连接，不能通过增大寻路爬阶阈值穿过悬崖。

## 玩家建造的桥梁与阶梯

在建筑定义的 `BuildingModules.Connection` 中启用通行连接模块。桥梁、阶梯仍使用既有蓝图、费用、施工、移动和拆除流程；没有另外一份需要人工维护的运行连接资产。

| 配置 | 含义 |
| --- | --- |
| 建筑占地 X | 通道宽度；平桥至少 3 格，其他通道最大 32 格 |
| 建筑占地 Z | 包括两端支撑的总长度，3～128 格 |
| 出口相对入口高度等级 | 0 为平桥；正整数为阶梯，上限 32 |
| 双向通行 | 关闭后只能从入口前往出口 |
| 桥下最小净空 | 世界单位，默认 1.5 |
| 损坏后的移动成本倍率 | 默认 2，越大越慢，必须不小于 1 |

本地 Z 的第一排是入口，最后一排是出口。旋转 0～3 对应 Unity Y 轴的 0°、90°、180°、270°；占地宽度和端口一起旋转。下降方向通过旋转阶梯实现。

放置时检查整排端口是否落在可建、可通行、同一地表与高度的支撑上，并验证配置高差、占地、边缘区、地形条件及跨度内部净空。模型锚点取入口高度。建造预览显示随高差上升的占地和两排端口。

施工只占用建筑位置，不提供上层通道；施工完成后自动创建桥面/坡面及连接。整个占地只允许这一个建筑，因此桥面不能再放建筑。桥下的独立地面路线仍可通行；阶梯下方净空不足的地面节点会被阻挡。

道路和通行建筑受损后保留通行，连接使用损坏成本；进入修复状态也不断路。拆除沿用白天限制，成功后移除该建筑的连接并释放占地。显示模型应使用保留桥体的损坏表现，不能给道路/桥梁配置坍塌掉落动画来表达降速。

## 固定地编通道

初始化地图会创建“导航地表与连接”子对象并添加 `MapNavigationAuthoring`。旧场景可重新点击初始化补齐，或手工添加组件。

在组件的“固定斜坡/桥梁连接”中配置稳定连接 ID、占地左下格、宽度与长度、朝向、入口与出口地表 ID、入口等级、上升等级和通行方向。固定通道当前使用 1.5 世界单位净空；需要不同净空的可建造通道在建筑模块中配置。

选中该对象后，Scene 视图用青色标记入口、黄色标记出口、紫色连线显示每条逻辑车道。按这些端口对齐 TWC 斜坡或显示模型，再执行地图烘焙。烘焙拒绝错误端口、重复 ID、地形穿入以及交叉通道净空不足。

固定连接数据随外层场景保存；TWC 绘图保存在 Data/Source。烘焙把额外地表和连接写入 Data/Generated 的 MapAsset，运行时建立派生导航图，不需要手改生成文件。

逻辑高度单位由地图配置决定；地编应按入口、出口和高度轨迹对齐坡面。平桥在 Layer 编辑、建筑放置和最终 MapAsset 烘焙三层都强制至少 3 格宽。

## 单位与存档

Landsong 的分层节点是地图权威数据，运行时转换为 A* Pro PointGraph。桥上、桥下和额外平台保留独立高度节点；楼梯/坡面保留连续高度轨迹与单向规则。ABPath 负责路径搜索，ECS RVO 负责动态单位避让。

平桥按一般地面处理，允许横向移动和迎面 RVO 避让；不再维护单格桥或窄通道方向准入仲裁。地图制作必须提供不小于 3 格的平桥实际宽度。

导航图和缓存不写入存档。恢复既有地图和建筑位置、旋转、施工/损坏状态后重新生成图；地图的静态地表与连接参与内容签名，改变这些数据后旧档不能冒充同一份地图内容。

## 验证与当前范围

Unity 菜单：`Landsong → ECS → Verification → Terrain connections`。报告：`Library/LandsongEcs/terrain-connections.txt`。

定向回归覆盖分层地表、单向楼梯、宽桥迎面通行、桥下独立单位、施工/完成/损坏/拆除和存档恢复，并显式拒绝小于 3 格的平桥。本轮需在 Unity 刷新脚本后重跑该入口，不沿用旧 PASS 记录。

地图工作流另有 21 项验证，包含初始化、复制隔离、全图重新烘焙和失败回滚。全项目回归中仍有与本次连接无关的 UI 配置失败，详见 `Library/LandsongEcs/ui-configuration-verification.txt`，不能宣称整个项目全部验收通过。

当前连接是矩形直通道和直线坡面。弯桥、转折楼梯、复杂人群压力测试、模型脚步动画及相机软硬边界仍需单独验收。`Map_TWCFlowLab` / `Map_NavigationLab` 是专项实验资源，不是正式游戏地图。

# Landsong 当前基准

更新日期：2026-09-22。本文档描述当前代码与资源组织。静态审查修复范围、当前验证结果与剩余限制见 [问题修复记录](ECS/问题修复记录20260917.md)，不使用历史 PASS 代替本轮验证。

Unity **6000.3.24f1**；Entities **1.4.8**；Entities Graphics **1.4.21**；Addressables **2.9.1**；A* Pathfinding Project Pro **5.4.7**；Easy Save 3 **3.5.26**。游戏使用 ECS 权威状态，导航搜索与局部避让由 A* Pro 执行，存档封装、压缩、文件、备份与设置持久化由 ES3 执行。当前 ECS 快照 **v36**，ES3 王朝封装 **v4**；旧快照即使可解码，仍须通过内容指纹校验。

## 项目规范

项目已集成Addressable、Easy Save 3、Odin Inspector、Behavior Designer Pro 3 和 A* Pathfinding Project Pro 5.4.7。已有能力优先使用插件 API，不在项目内重建并行实现。

- Log日志使用中文
- 需要在检查器填写的字段使用 `[LabelText("中文"), Required]`；缺失引用是配置错误，不在运行时扫描或推测。
- 项目编辑器功能统一放在 `Landsong/` 菜单下。

## 从哪里开始

打开 `Assets/Landsong/Scenes/Boot.unity`，进入 Play：开幕展示 → Start 主菜单 → LoadingTransition → Game。当前游戏菜单地图为 **Map_Map01**。运行地图 Mesh 是本地可重建产物，不进入 Git；首次检出、清理生成目录或制图输入变化后，进入 Play 前会自动补齐，Player Build 前也会再次检查。

四个入口场景通过显式 ApplicationSceneEntry 引用同一个 `Bootstrap/UI_Root.prefab`，运行时保留一个根 Canvas、UIManager 和 EventSystem。Start、Game、Loading、Setting、Save、Confirm 等根面板按需加载；设置与存档浏览共用同一套面板，游戏 HUD 及其功能子面板归属于游戏会话。检查器引用缺失是配置错误，由编辑器制作和校验修正。Input System 自动生成代码随输入资产保存，不手工维护。

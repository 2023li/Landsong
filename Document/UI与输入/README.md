# UI 与输入

所有现有文字使用 TMP，其他控件采用默认 UGUI。基础界面直接保存在 Boot、Start、LoadingTransition、Game 各自的 ECS UI 下；没有独立的整套 UI Prefab。

Game 默认隐藏，由加载完成的 EcsGameHost 启用。科技研究 HUD、科技树、军团/英雄 HUD、功能面板标题/关闭按钮、共用设置、存档浏览、画像/家谱等由 Scripts/ECS/Presentation 动态创建；美术调整需区分场景绑定与代码生成布局。

## 主要入口

- 建筑按钮展开底部横向图标栏；上方分类只列有蓝图的建筑类别。图标悬浮显示名称、放置成本和每回合消耗，材料不足仍展示已解锁建筑。
- 点击已有建筑收起目录和主滚动区，默认打开新版右侧详情及 Buff / 道路加权行动力 / 实际资源路径。顶部输入框改名，图标下 style 打开皮肤选择；红色感叹号悬浮解释异常。经验满且无更高等级显示 MAX，灰色升级按钮可点击查看阻碍，可升级时确认材料。岗位预算箭头、自然/已付吸引力条、最多 10 个岗位标记和圆形作物选择/成熟条/X 铲除按类型显示。施工、维护、生产、住宅、仓储、采集、神殿等适用信息保留在中部滚动区，坐标及移动力固定底部。详情不展示连接候选列表。核心不显示耐久、不允许拆除。
- 军事管理为两个滚动视图：左边已驻扎/空槽，右边未驻扎，支持比较、交换、指定槽、一键填空槽及兵种筛选。
- 情报是独立按钮/地图模式，不以事件弹窗发布预测。
- 科技许可解锁后，任务追踪下方显示可点击的研究 HUD：图标、当前研究名称、进度条、研究状态/点数和效果摘要。HUD 代替工具栏独立“科技”按钮；点击定位研究队首，队列为空时显示选择研究的入口。取消、完成、重新规划和恢复存档后自动更新，不在表现层推进研究。
- 经济、库存、任务追踪、人才、王室、政策及战报分别读取对应 ECS 数据。历史窗口支持分类、回合、来源/文字过滤、分页、定位和筛选收支汇总。
- 王室家谱使用横向世代灰带、蓝色家庭框和并排人物白卡，肖像使用统一模块化合成；死亡人物置灰，现任国王独占右上角皇冠标记（美术未配置时显示“王”），历史登基子代使用金色亲子线。历史世代不截断，支持双向滚动、缩放和固定关闭按钮。
- 王室采用左家谱、右详情布局，原左侧人物列表被移除。右侧点击卡片切换人物，正文滚动，底部固定立储/赐死/赐婚/处理请求；“王朝事务”标签承载原全局操作。退出王室时共享滚动面板恢复原布局，不影响人才、政策或其他窗口。
- 主动赐婚：人物详情 → 赐婚 → 候选名单 → 点击候选查看双方详情 → 确认赐婚；支持重新选择、取消，未婚成年国王及亲生子女均可发起。名单候选由 ECS 准备，关闭窗口不会删除人物或重抽属性。性别及父母信息来自持久人物数据，声望映射已有 Influence。
- 赐婚请求在科技 HUD 下方显示可点击待办，王室面板也列出全部请求。弹窗两侧展示双方详情，下方同意/不同意/稍后处理；关闭或 Esc 不影响请求，不消耗随机数。弹窗阻断地图操作及功能切换，实际裁决仅限未暂停的白天，由 ECS 重新核验参与者和请求回合。

## 功能面板的打开与关闭

进入 Game 时没有默认展开的功能面板，主/副滚动视图均隐藏。点击对应功能才展开内容；普通面板的标题与“关闭”按钮固定在滚动内容外，滚到末尾仍可关闭。关闭后不重新打开建筑提示页，定期刷新也不会把面板重新显示。

科技树、任务窗口、家谱/人才/政策图均有固定关闭按钮；驻军关闭时同时收起两个滚动区。建筑目录保留底部栏自己的关闭按钮。关闭情报同时提交退出情报模式命令，恢复地图操作。关闭历史同时隐藏搜索框；返回面板保留有界导航历史，没有历史时关闭当前面板。

建筑操作确认保持取消/确认流程，关闭功能面板不能绕过当前确认。王朝终局必须选择恢复或结束王朝，不能直接关闭。Esc 的暂停菜单优先级不变；普通功能面板可直接使用各自关闭按钮。

实现入口：EcsGameView.Panels.cs 管理展开状态和固定标题，EcsGameView.ResearchHud.cs 构建研究 HUD；原有 Game 场景 TechnologyButton 引用在运行时移作 HUD，不再保留重复工具栏入口。

王室人物详情底部固定提供“立为储君 / 赐死 / 赐婚 / 处理请求”。“处理请求”打开该人物的可滚动待办列表，包含搁置赐婚、远征愿望（待安排/远征中）、丽质塑容及未完成的人才委托；空列表明确提示。家谱肖像以橙色“! 数量”标记未完成请求，不占用皇冠位置。查看赐婚进入双方详情；安排远征跳转并预选队长，归来才完成；委托提交沿用原物品和好感规则。列表有固定关闭按钮，Esc/返回先关闭列表，关闭不处理请求。列表打开时阻断底层面板切换和玩法输入，状态失效及时刷新，死亡后关闭。

## 主菜单

主界面按顺序显示“继续游戏”“开始新王朝”“加载游戏”“设置”“退出到桌面”。没有可读的最近王朝记录或有效备份时隐藏“继续游戏”；继续使用最近王朝的持久节点，白天未保存的操作不会自动恢复。

“开始新王朝”只打开配置面板，在其中填写可选王朝名称、选择地图、查看说明/缩略图并选择简单/普通/困难（默认普通）。本轮难度仅为界面草稿，数值效果待策划定义，不写入玩法状态或存档。“不刷新小偷”为禁用占位，暂不执行特殊规则。点击“建立王朝”才进入加载流程；返回后保留当前菜单会话的配置草稿。

“加载游戏”复用跨王朝存档浏览器，可选自动节点和任意独立槽，并保留备份恢复、重命名、删除与覆灭记录入口。“设置”使用共用设置页。“退出到桌面”须确认，取消或 Esc 返回菜单。配置内 Esc 优先收起展开的下拉框，再返回主菜单。

基础菜单按钮与地图下拉框继续复用 Start 场景绑定，布局及新王朝配置面板由 EcsMainMenu 的 Management / NewDynasty 分部动态生成。

## 暂停与设置

Esc 或“暂停 / Esc”打开暂停面板，收拢保存、快速保存、设置、回到游戏、回到主菜单、退出游戏。子页 Esc 返回来源；关闭暂停恢复打开前的暂停状态。返回菜单和退出均有确认。

“保存”创建独立白天存档；“快速保存”覆盖当前手动槽。槽可命名、指定覆盖、重命名、删除、查看缩略图和载入备份。实时夜晚不能保存战斗状态，见 [存档](../运行时与存档/README.md)。

设置页在主菜单和暂停页共用：主/音乐/音效/环境音量、静音、显示/分辨率/画质、界面缩放、镜头速度/灵敏度/缓动、减少动态、高对比度、消息偏好、语言和七项键位。草稿点击应用才保存；显示变更在 15 秒内再确认，关闭或超时恢复。恢复默认也先改草稿。

## 输入规则

WASD 平移、中键拖图、Q/E 旋转、滚轮缩放，镜头限制在地图范围。R 旋转放置，右键取消建造；空格暂停模拟。英雄用卡片/数字 1～9 选择，右键合法地面移动，H 驻守，反引号取消选择；Esc 仍优先暂停。允许配置的快捷键不得占用保留键。

UI 起点认领拖动；从面板开始不会转成地图操作。TMP 输入框聚焦时阻断镜头/英雄快捷键。情报模式不暂停夜晚，但禁止建造、英雄下令、警铃、拾取等玩法操作。共用行复用并保留滚动/选择，刷新不打断正在编辑的内容。

提供基础单指/双指、长按英雄移动操作；这不等于真实触屏设备或手柄验收。所有 UI 均只有展示/输入状态，费用和权限必须由 ECS Command 再次检查。

## 肖像与丽质

家谱、右侧详情、人才卡、赐婚双方、驻军/士兵详情和英雄 HUD 共用 PortraitImageBinding。默认 16 岁之前显示带人物基础颜色的摇篮/襁褓占位；之后显示模块化面孔，衰老由程序生成。死亡人物的 Image 统一置灰。

有“丽质”且达到青年年龄的人物在功能面板关闭时出现 HUD 提示，并在“处理请求”和家谱请求标记中计数。点击“塑造容貌”进入左右分区的捏脸弹窗：左侧实时预览，右侧在已有且性别兼容的部件中切换，并调整肤色/发色/眼睛 RGB；底部固定“确定容貌（仅一次）/稍后再定”。预览和关闭不改 ECS，不消耗机会；白天确认通过 CustomizePortrait 命令一次提交。之后不再允许捏脸，仍程序化衰老。暂停/夜晚不能确认，弹窗拦截底层玩法输入；Esc/返回优先关闭。

任务窗口为“已接受 / 邀约”两列，槽位内点击展开要求和奖励。已接受任务显示承接槽提供建筑，详情补充原邀约来源；两侧都有名称/坐标。X 确认放弃，完成变绿并改为 ✓ 确认领奖，主线与一般任务使用同一组通用槽位，标题显示合计占用；首次主线无空槽时显示等待。分步任务成功领奖后，下一步保留原槽及展开状态，整条链结束后才释放。额外前置未满足的后续步骤显示等待前置并保留槽位。固定关闭按钮不随列表滚动。容器失效丢失任务及处罚规则见 [任务系统](../任务系统/README.md)。

任务卡标题旁的 Toggle 勾选即追踪，取消当前勾选即停止追踪；同一时刻最多追踪一项。HUD 完成任务直接“领取奖励”，成功后依后续任务优先、否则物品奖励总价值最高的规则自动选择下一项。邀约分类为独立多选 Toggle，全关显示空列表，任务按奖励价值降序排列、空槽在后。价值与并列规则见任务系统文档。

建筑基础产出已统一放入主滚动容器，合并库存、士兵槽、邀约槽、任务槽位。驻军独立模块支持横向滚动与槽位点击；士兵详情固定关闭按钮并支持 Esc，详情开启时拦截地图和底层面板操作，结束姓名输入通过 RenameSoldier 命令提交。新详情及建筑槽位按参考设计使用肖像占位，原军事列表继续使用已有肖像绑定。

士兵基础属性按两行展示力量、知识、敏捷和血量；敏捷直接读取原速度值，能力列表不再重复显示速度。力量与知识仍为未定义占位。

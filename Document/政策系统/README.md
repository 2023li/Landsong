# 政策

政策属于持久王朝选择，不是英雄或人才岗位。定义位于 ECSContent/Definitions/Court，Rule 描述修正；Level 决定分层，前置关系决定可用性，同组同层互斥。

界面按层显示卡片和前置线，选择与取消提交 ECS 命令。民意是生效门槛，不因选择政策直接消耗；低于门槛暂停效果但保留选择，恢复后重新生效。

当前占位政策：

- 宫廷宿卫：弑君风险 −60%，产能 −5%。
- 宗室议事：弑君风险 −30%，与宫廷宿卫同层互斥。

概率修正不保证弑君永不发生。有效政策可按规则参与政治、产能和情报汇总。编辑通过 Landsong/ECS/Court content and rules 浏览与校验；政治参数在 GameCatalog.Court。

王室继位和跨代政治遗留见 [王室与人才](../玩法系统/README.md)。当前卡片与数值为可编辑基准，不是最终美术和平衡。

# AI 与飞行物

DBP 只选择战术意图；ECS 的感知、接战位、导航、弹体与伤害执行器负责运行。所有普通攻击统一经飞行物，不由动画事件扣血。

## AI 规则

- 索敌仅考虑已部署、存活、入场保护结束的对立单位；按威胁加权距离评分，正在攻击自身的敌人额外提高优先级，完全同分按稳定 ID，不用随机数决定命中。
- 自动追击默认最多 8 秒、离追击锚点最多 12 单位。友军以驻地/英雄最后指定位置为锚点；驻地中心不可通行时返回可达外围。敌军结束临时追击后回到追击起点，再继续建筑目标。
- 玩家位置命令、召回和警铃仍优先于自动追击。未选中英雄继续最后位置的自动行为，不增加强制集火。
- 自动交战按稳定顺序分配不同接战位置：单位周围圆环、建筑外围可行走格。位置间按单位半径留间距；没有位置的单位等待，不挤入已占接战点。下一帧重评，目标/单位死亡后释放。
- Navigation 的 Burst Job 用局部空间哈希做软分离，包括重叠出生点的对称散开；不把单位当成静态寻路障碍，避免路口永久互堵。分离移动检查地形、建筑占用、对角切角和高度差。当前不是刚体碰撞或完整大军团流场。
- `SiegeOnly` 跳过单位索敌，直接执行既有建筑目标；`IgnoreSeparation` 不受软推离，但其他单位仍感知其体积。默认不启用例外。

## 配置入口

在士兵、英雄、敌人或建筑定义的 `Data.Combat` 配置：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| DetectionRadius | 24 | 感知距离，最大 64 |
| ChaseRadius / ChaseSeconds | 12 / 8 | 自动追击距离/时间上限；不限制玩家指定英雄移动 |
| BodyRadius | 0.35 | 软避让体积及接战点间距；大型目标的攻击距离从体积边缘计算 |
| Armor / Reduction / Penetration | 0 / 0 / 0 | 平减护甲、减伤比例、攻击穿透；减伤最多 95% |
| ProjectileMode | Tracking | Tracking 追踪单体，Ground 固定落点 |
| BlastRadius / WarningSeconds | 0 / 0 | 爆炸范围、落点攻击起飞前预警；多个重叠弹体各自独立 |
| ProjectileLifetime | 10 | 总寿命，必须大于预警时间 |
| Traits / BlocksProjectile | None / false | 战术例外；建筑是否拦截飞行物 |

Boss 占位已配置 2.5 范围、1.2 秒预警、5 护甲的落点攻击；泰坦已配置 1.5 范围的追踪爆炸、5 护甲、2 穿透。参数是可调占位，不代表最终平衡。

地图环境使用 `MapAsset.Cells[].BlocksProjectile`，与可通行/可建造开关分离。启用后此格整列阻挡弹体，当前没有高度相关掩体或抛物线越墙。TWC 增量导入按地图坐标保留已有格子的 ECS 阻挡开关；新格默认关闭。建筑荒废/拆除后不再拦截。复杂地图验证边界见 [当前限制](../ECS/当前限制.md)。

## 飞行物与伤害

- 所有普通攻击仍先生成 Projectile，再统一提交 DamageRequest，没有恢复近战直接扣血。
- 发射固定伤害、穿透、阵营、模式、速度、寿命、预警、范围、落点及来源/目标身份。攻击者后续升级、失去 Buff 或死亡，不改变已发弹体的威力。
- 追踪弹目标死亡/消失后失效；落点弹不再跟踪目标，目标离开或死亡仍按原位置落地。Ground 默认显示红色范围点环，暂停冻结预警和弹体运动。
- 弹体每帧对实际经过线段（包括最后命中容差段）做网格 supercover 检测，高速弹不会跳过单格障碍；阻挡后消失，不穿墙爆炸。命中的目标建筑自身占地不拦截指向它的弹体。地图外和不存在的格子按边界拦截；现有格子的通行标记不决定弹体遮挡，尚不支持跨空洞或按弹道高度越墙。
- 范围按落点附近敌对单位/建筑计算，每个目标每发弹体最多一次；检查到目标的环境遮挡。不伤友军，不做随机命中。范围作用于整栋建筑一次，不按占地格重复伤害。
- 伤害为 `max(0, 原伤害 - max(0, 护甲 - 穿透)) × (1 - 减伤)`；完全抵消不记有效参战。实际生效后进入个人参战和死亡流程，英雄支援扩展仍沿用 RecordHeroContribution。
- 暂停不消费待结算伤害；离开战斗/撤退阶段后清理残留伤害，不在白天补打上一夜攻击。

## 黄昏快照与回合战力

军事修正规则：RangeBonus、AttackSpeedBonus、SpeedBonus、ArmorBonus、DamageReductionBonus、PenetrationBonus、ProjectileSpeedBonus、BlastRadiusBonus。均沿用科技、人才、Buff、有效建筑来源汇总器及 Target 定义筛选。射程/移速/弹速为比例，攻速按 `Interval / (1 + 加成)` 换算；护甲/穿透/范围为加法，减伤按比例加法后限制。

NightPreparation 保存单位的生命、攻击、速度、射程、间隔、弹速及完整 CombatProfile；并保存建筑的防御配置。建筑本体耐久仍由建造/等级规则负责。夜间来源损失不会改变已锁定军事加成；准备前及下一回合重新评估。士兵/英雄成长继续叠加各自持久经验，回合开始的威胁预算不会因白天调整再升高。战力估算纳入攻速、防御，不承诺是精确战斗胜率。

持久军事准备与内容签名一起校验。TacticalState、接战位和在途弹体不保存，节点恢复从夜晚开始重新生成，不保存战斗逐帧状态。

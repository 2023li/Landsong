# 情报系统

## 玩家操作与信息边界

- 点击“情报”进入情报模式；普通圆点表示内容更新，没有预测事件弹窗。界面分为完善度、当晚军情、宫廷情报、图例和来源。点击有效建筑来源可以移动镜头定位。
- 当前完善度为 0～100；本夜已知完善度只升不降，白天拆除/停运、同回合恢复节点不会遗忘。下一回合重新统计；核心失守后重开，使用已有恢复票据的新种子更新报告并标记未读，不显示尝试次数或降难信息。
- 默认档位 1 / 40 / 75：未知不给夜晚类别；低档仅类别与回合初威胁等级；中档白天给怪物类型和必含真实数量的区间；高档白天按类型汇总准确数量并给 Boss 方位。没有逐波数量表、精确属性、刷怪秒数或种子。
- 实时阶段不重复显示白天数量表，只显示来袭方向。中/高档默认提前 12 / 24 秒进入可选方向组；同时间多入口合成一组。支持切换已经侦察的组，实际波次推进后自动回到下一组；其他已知入口以浅色显示。
- 橙色虚线表示大致出生区域；红色十字表示可能受袭建筑区域。两种图形兼顾色觉辨别，线宽随镜头缩放。区域不表示精确建筑占地、路线或出生格。
- 情报模式不会暂停夜晚，只允许查看、镜头、切换与退出；UI 和 ECS 命令层都拒绝建造/入夜/英雄/警铃/拾取等玩法操作。Esc 暂停菜单仍有最高优先级。恢复节点、终局及主动退出会同步释放模式。

## 来源制作

在现有定义 `Rules` 中配置 `Intelligence`，共用正式内容资产。

| 字段 | 含义 |
| --- | --- |
| Amount | 来源贡献，1～100；全部有效来源合计上限 100 |
| Level | 建筑适用等级，沿用现有等级匹配；非建筑用 0 或 1 |
| B | 最低工人数，仅建筑可用；0 表示无需工人 |
| Target | 可选前置科技 ID；留空表示无科技条件 |
| Secondary / C / Value / Extra / Key | 情报规则不使用 |

建筑必须处于 Operational 且维护已满足，再检查工人和科技。科技完成后的 Entitlement、事件奖励等 Buff 的有效 Entitlement、已选择且民意/前置满足的政策都可以提供点数。来源列表给出未获得、未运营、维护不足、工人不足、缺少科技等原因；科技详情也显示被动情报贡献。事件通过现有 Buff 授予/撤销路径接入，不自行创建永久情报累计字段。新增定义仍须登记 GameCatalog；是否提供情报由其规则决定。

正式占位瞭望塔：`Assets/Landsong/ECSContent/Definitions/Building/b瞭望塔.asset`，保持 2×2、2 回合建造、每施工回合 60 金币；40 点情报，要求 2 工人，基础吸引力 75，维护每回合 1 金币。完工按现有流程在空闲人口允许时配置初始工人；不足时需要通过岗位界面补齐。数值可继续调整，未承诺最终平衡。

档位与提前量在 `GameCatalog.asset → Settings` 的 `LowIntel / MediumIntel / HighIntel / MediumIntelLead / HighIntelLead`；档位须严格递增、最高不超过 100，提前量为正数且高档不小于中档、不超过 120 秒。

## 单一计划与空间可信度

- 回合开始锁定事件、战力预算和编成。白天布局修订调用同一个 `NightSpatialOps` 可达性/目标规则，只重投影目标和合法出生点，不改变数量、类型、预算和时间。
- 黄昏按照最终布局再次重投影，再保存节点。出生预测区位于 Authoring 区域内，计算时使用真实分批出生的同一偏移和合法点投影，覆盖该股敌军的所有实际出生点；高档区域不大于中档。
- 不可用入口不显示为当前可选方向。夜间实际敌军失去目标后，红区读取存活敌军的新目标，不继续绘制已失效的旧波次目标；骚扰敌人的红区包含附近可能波及范围。
- 区域计算缓存仅加速视图；键含区域、数量、位置、档位和地图修订，恢复节点时清空，不持久化、不充当模拟权威。0.25 秒更新意味着标记最多有一个刷新周期的显示延迟。

## 节点恢复

最高已知完善度和报告/已读指纹保存到节点外元数据，同王朝同回合的手动槽或白天/黄昏回退不会遗忘已知。核心重开票据换种子时刷新报告；旧已读请求不能清掉新报告圆点。情报模式和区域缓存仅属临时状态，恢复时清空。

# 昼夜与战斗

一个回合是白天 N + 夜晚 N，黎明后才进入 N+1。白天建造经营，点击“下一阶段”先预演结算与损失；确认后保存黄昏节点，军事建筑全部驻军按槽位分批自动出勤巡逻。

| 阶段 | 当前规则 |
| --- | --- |
| 白天 | 建造、管理、配置、情报查看与保存；回合初已锁定敌军基础计划 |
| 入夜准备 | 默认 3 秒，计入夜晚总时长；驻军分批出场，字幕与下一阶段按钮隐藏 |
| 平安夜 | 与战斗夜统一默认 300 秒；准备结束显示配置字幕和下一阶段按钮，可手动跳过。保留 1×/2×游戏时间速度 |
| 战斗夜 | 固定 1×；全部波次处理完且无存活敌军后，2 秒显示胜利字幕，再过 2 秒欢呼，再过 3 秒显示“下一阶段”；等待期间欢呼结束后继续巡逻 |
| 夜晚收尾 | 默认 10 秒；依次处理撤离、胜利提示与欢呼，结束后自动结算并进入黎明 |
| 黎明阶段 | 默认 3 秒，属于新一天；允许建设管理，隐藏“下一阶段”按钮，日出结束后重新显示 |
| 归营 | 黎明开始时，幸存士兵/已出场英雄沿导航回到驻地附近，抵达才隐藏；归营与白天并行，不阻塞下一阶段 |
| 战报 | 黎明自动结算并归档，可在白天查看，不设置确认阶段 |

胜利字幕只表示本夜清敌完成，收益仍走原有战报与黎明提交。幸存士兵恢复满状态，倒地视为死亡；PlayerHome 失守为游戏终局，玩家选择结束王朝或回白天/黄昏重新进行。参数与边界见 [夜晚阶段与归营](夜晚阶段与归营.md)。

## 夜晚计划

GameContentSet 的 Night 与 NightEvents 配置流程参数及事件条件、优先级/权重、周期、冷却、一次性、波次和 Boss 后续。回合开始检测条件并锁定事件、基础预算、编成；白天布防不再次增加本夜预算，只重新投影合法目标和出生位置。

基础威胁为 min(回合×ThreatPerTurn + 战力×StrengthRatio, ThreatFloor + 战力×ThreatPerStrengthCap)，再乘事件倍率。战力计入有效驻军、满足建筑/工人条件的已招英雄部分权重、设施与有效加成，避免大战损后仅按回合线性增加。

自定义 WaveTimes 使用正式夜晚时间比例，必须首项 0、严格递增且小于 1，并与 WaveCount 等长；为空时按 `Night.WaveIntervalSeconds` 排程，默认最大间隔 15 秒且全部默认波次位于前半夜。当前波敌军提前清空时，下一股待定波次会立即进入已有的入场预警，不继续空等原计划时刻。普通入侵不能混入 Boss。每夜从未被建筑隐性范围覆盖的可通行空格动态选择区域，城内空地也可参与；无普通候选时只在地图绘制的边缘区兜底。实际入场必须位于当夜对应区域内、未被建筑占用且有可达目标，否则取消该股入侵并提示。详见 [动态刷怪](../地图系统/动态刷怪方案.md)。

黄昏冻结当夜军事准备，不因夜间来源建筑荒废撤销已经锁定的整夜加成。敌人当前目标荒废/不可达时优先攻击原目标附近可达建筑，再回退核心，无目标撤离。

Boss 未死则撤离形成持久后续事件，再次来袭满生命；被击杀清除对应威胁并提供额外掉落。核心重开重新生成种子并只降低当夜难度，情报同步刷新，玩家界面不显示此前尝试。

# 昼夜与战斗

一个回合是白天 N + 夜晚 N，黎明后才进入 N+1。白天建造经营，点击“下一阶段”先预演结算与损失；确认后保存黄昏节点，军事建筑全部驻军按槽位分批自动出勤巡逻。

| 阶段 | 当前规则 |
| --- | --- |
| 白天 | 建造、管理、配置、情报查看与保存；回合初已锁定敌军基础计划 |
| 出勤 | 默认 2 秒铺垫，敌人入口提示与入场保护；首敌解除保护后开始战斗时钟 |
| 平安夜 | 默认 15 秒，可 1×/2×，与战斗互斥；可能多次出现小偷/精灵，不保证有互动，结束自动黎明 |
| 战斗夜 | 固定 1×，月亮只显示进度；到时敌人开始撤退 |
| 撤退与收尾 | 默认撤退约 5 秒，随后固定 10 秒庆祝/救助与拾取 |
| 今晚战报 | 按钮先打开战报，另点确认才提交黎明，不以点击打开代替结算 |

没有一般性的胜利/失败结算，只有战损。幸存士兵恢复满状态，倒地视为死亡；PlayerHome 失守为游戏终局，玩家选择结束王朝或回白天/黄昏重新进行。

## 夜晚计划

GameCatalog.Night / NightEvents 配置事件条件、优先级/权重、周期、冷却、一次性、波次和 Boss 后续。回合开始检测条件并锁定事件、基础预算、编成；白天布防不再次增加本夜预算，只重新投影合法目标和出生位置。

基础威胁为 min(回合×ThreatPerTurn + 战力×StrengthRatio, ThreatFloor + 战力×ThreatPerStrengthCap)，再乘事件倍率。战力计入有效驻军、满足建筑/工人条件的已招英雄部分权重、设施与有效加成，避免大战损后仅按回合线性增加。

事件波次时刻用战斗时长比例；自定义 WaveTimes 必须首项 0、严格递增且小于 1，与 WaveCount 等长；为空时默认均分至 80%。普通入侵不能混入 Boss。生成点必须在对应入口带内、可走、离建筑足够远且有可达目标，否则取消该股入侵并提示。

黄昏冻结当夜军事准备，不因夜间来源建筑荒废撤销已经锁定的整夜加成。敌人当前目标荒废/不可达时优先攻击原目标附近可达建筑，再回退核心，无目标撤离。

Boss 未死则撤离形成持久后续事件，再次来袭满生命；被击杀清除对应威胁并提供额外掉落。核心重开重新生成种子并只降低当夜难度，情报同步刷新，玩家界面不显示此前尝试。

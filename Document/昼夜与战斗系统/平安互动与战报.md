# 平安互动、掉落与战报

## 玩法与数据入口

- 正式目录 `Assets/Landsong/ECSContent/GameCatalog.asset` 的 `Peaceful`：默认每夜最多 3 次、同时最多 2 次、总盗窃价值 15、首次 2.5 秒、检查间隔 2.5 秒。不是保证每晚有机会；缺少来源、合法路线或响应单位时取消本次刷新。
- `Definitions/Opportunity/night.visitor.asset` 为小偷，保留原稳定内容 ID；`night.fairy.asset` 为独立精灵。默认权重各 100、每种最多 2 次、出现时窗为夜晚的 15%～50%、速度 1.2、路线约 8 单位、最低响应 4 秒、抓捕半径 1.2、响应半径 25；数值是可编辑占位。
- 物品定义 `Data.Theft`：Protection 可组合排除任务/唯一/绑定物，Weight 为物品类型权重，Maximum 为单次数量上限，UnitValue 为预算价值。默认 100 / 5 / 1；不可堆叠物不参与。不因为普通资源被任务要求，就自动把普通资源变成任务专用品。
- 敌人普通奖励沿用 RewardItem / RewardBlueprint / RewardBuff / RewardFeature，直接入夜间奖励账。SpecialDrop 规则仅用于敌人：Target=物品、Amount=数量、B=稀有度 1～3。Boss 增加 20 金币的金色特殊掉落占位，普通收益仍保留。

## 平安夜执行

来源建筑按稳定 ID 列举、等权抽取，不按库存格数量加权。小偷仅从有合格现货的正常建筑附近生成；精灵不要求现货。同一建筑同时最多一个访客，生成前重新检查来源、时段和空间条件。

出生点位于建筑占地外的可行走格。逃离使用四邻格、检查高度和建筑占用的短路线，方向朝地图外围；没有合法向外出口则取消。刷新还检查士兵/英雄能否在留出 1 秒反应时间后拦截，不会预先选定或预留赃物。

点击访客优先指派可及时赶到的已选英雄，否则按可行拦截点与稳定 ID 选响应单位。单位使用 ECS Capture 位置命令，由现有 DBP 和 Navigation 移动；接近抓捕半径才成功，不通过伤害系统，不增加战斗经验。召回中的士兵不可响应，同一单位不能认领两个访客。警铃可指派范围内单位；玩家新移动/召回命令可打断响应。路线失效或没有可用单位时取消，不扣资源。

未抓到的小偷在离开/黎明时才按独立随机状态，从绑定来源当前的合格物品中抽取，受数量和全夜价值双上限限制。来源变空时损失为零。实时通知不透露物品明细，结算记录保留来源建筑名称快照、阻止盗窃、逃离、取消、零损失和实际被盗清单。即使白天停留在战报面板后直接入夜，该面板也只显示尚未结算提示，不泄漏本夜被盗载荷；只有白天/Report 阶段开放详细战报。

## 掉落、收尾和战报

普通击杀收益直接暂存；只有 SpecialDrop 生成场景拾取物。特殊掉落具有合法落点、稀有度光柱、扩大点击区、TMP 世界/画面外标记和飞向 HUD 的占位反馈。直接点击无单位距离要求，不消失；十秒收尾结束时自动收取全部。找不到合法落点时直接记入奖励账，不丢失奖励。逃跑、未生成、强制清场不触发击杀奖励。

仍是“战斗 → 固定十秒收尾 → 今晚战报 → 确认 → 黎明”，没有增加第二个夜晚时钟。清场用黄色举臂占位，撤退用警戒标记，居民/建筑损失或较高单位阵亡比例用蓝色救助标记。存活单位恢复满状态；平安夜不追加庆祝阶段。动画与音频通过 [表现配置](../音频与本地化/表现与语言制作.md) 接入。

战报区分士兵/英雄/居民死亡、工人失业、建筑荒废、来源库存损失、被盗物资、全部收益及溢出；包含已付供奉、供奉经验、出场费、有效参战秒数、战斗经验和 Boss 击杀/撤离后续。首次名称快照不因之后改名/实体销毁改变。供奉在白天结算已支付，只展示，不在黎明再次扣款。

夜间奖励仍用 NightReward 来源/条目去重，点击只登记，黎明先提交荒废损失，再入库，满仓进入待存放。待存放在下一夜之前继续走既有损失确认。战报确认后保存已提交历史，最多约 2048 条、按完整回合淘汰旧记录；保留最近一整夜，不截断成半份战报。白天可在战报面板展开历史。通用历史页另提供筛选、分页和来源定位。

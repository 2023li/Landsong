# 启动、加载与场景

| 场景 | 职责与制作位置 |
| --- | --- |
| Assets/Landsong/Scenes/Boot.unity | Logo / 开幕展示；EcsBootScreen.SplashSeconds 默认 2 秒，不创建王朝 |
| Assets/Landsong/Scenes/Start.unity | 继续、新王朝配置（地图/难度占位/特殊规则占位）、加载游戏、设置、确认退出 |
| Assets/Landsong/Scenes/LoadingTransition.unity | 卸载旧地图、加载 Game / SubScene、初始化或恢复，显示真实阶段进度 |
| Assets/Landsong/Scenes/Game.unity | 共用相机、灯光、UGUI、输入和各地图 SubScene 引用 |

Build Settings 只启用以上四场景，顺序固定。SubScene 通过 Game 引用进入构建，不作为菜单入口。正常返回为 Game → LoadingTransition → Start，不重复开幕。直接在 Game 点 Play 会回菜单；从 Start 点 Play 可跳过开幕。

## 加载与输入

Game 相机、界面、EventSystem、灯光在磁盘上默认关闭。EcsGameHost 等待地图实体、SimulationReady 和恢复成功后统一启用。编辑布局可临时启用预览，保存前恢复关闭并保留 Host 引用。

进度只在真实阶段完成后推进。实体加载没有精确字节进度时停留于该阶段；默认地图等待超时 120 秒。失败/取消先释放已经加载的资源，再返回菜单；取消主场景异步加载需等待激活后安全卸载。不会覆盖原存档。

## 地图目录

- Scenes/MapScenes：TWC 源场景、配置和烘焙网格。
- Scenes/EntityMaps：每张地图的 GameWorldAuthoring 与地形编辑 SubScene。
- ECSContent/Maps：地图逻辑 MapAsset。
- ECSContent/MapMenuCatalog.asset：唯一地图 ID、显示名、说明、缩略图。

新增地图创建独立 MapAsset 和 `EntityMaps/<MapId>_Entities.unity`，每个 SubScene 只有一个 GameWorldAuthoring。菜单目录与 Game 中 EcsGameHost.Maps 使用对应索引，引用的 AutoLoadScene 全部关闭，由加载流程选择一张。具体制图见 [地图制作](../地图系统/README.md)。

UI 继续使用 Canvas、RectTransform、Image、Button、ScrollRect、TMP_Text、TMP_InputField、TMP_Dropdown。基础结构在各场景 ECS UI 下，动态窗口在 Presentation 中生成。四场景各自保持唯一有效 AudioListener。

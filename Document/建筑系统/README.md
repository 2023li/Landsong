# 建筑

建筑是核心玩法，包含蓝图、分类目录、放置与道路、分级/经验/皮肤、岗位、维护、资源连接、生产、住房、农田/采集、荒废、修复、移动和拆除。

编辑入口为 Assets/Landsong/ECSContent/Definitions/Building，使用 18 个独立功能模块，详见 [建筑模块配置](../ECS/建筑模块配置.md)。定义的 Prefab 指向完整建筑根；模型按用途、等级、施工步和皮肤配置，见 [模型制作](../ECS/建筑玩法与制作工作流.md)。

## 操作与费用

底部建筑栏按已拥有蓝图列类别和图标，悬浮显示名称与费用；选择后左键放置、R 旋转、右键取消。点击已有建筑收起建筑目录和主滚动区，默认打开右侧详情及地图范围，浮动操作条保留移动、升级、修复、拆除等入口。详情顶部为图标、style 皮肤选择、可直接编辑的名称、等级与蓝色经验条。改名在结束编辑时通过命令提交，空名称恢复默认；库存和驻军继续使用实例名，身份仍为稳定 ID。

经验达到需求且没有更高等级时显示 MAX；其余状态显示升级按钮。可升级时打开材料确认，灰色按钮仍可点击说明缺少高级蓝图、经验、工人、维护、材料等原因。没有基础产出的建筑隐藏整个基础产出块，且不保留布局空位。有产出时，基础产出位于主滚动容器首部，汇总人口容量（含核心基础人口）、科研值、库存容量及其工人条件、士兵槽、邀约槽和任务槽位，不再重复列出各项独立说明；实际停工和异常由警告说明。红色感叹号悬浮展示耐久受损、缺工、维护/食物/环境/补贴不足、资源不可达、远征锁定及施工/荒废/修复状态，离开隐藏。

岗位和种植为独立模块：岗位显示实际人数、按份调整的补贴预算、自然/已付补贴吸引力和最多 10 个比例岗位标记；种植圆钮打开作物列表，选择后子图标优先读取作物 Icon，未配置时使用收获物品 Icon，绿色进度表示成熟度。已种植时更换前先用 X 确认铲除；手动/自动收获沿用原入口。详情中部滚动，顶部身份和底部世界坐标/移动力固定，关闭按钮不会随内容滚走。施工/修复、维护/物品生产、住宅食物/税收、仓储、采集、神殿供奉等块按适用条件保留；驻军独立成块，显示人数/容量与“调整驻军”按钮；下方横向滚动条按真实槽号展示白框、实际士兵肖像及姓名，死亡士兵置灰。点击已有士兵打开详情，点击空槽打开驻军面板。

移动保留 ID、等级、岗位、库存、驻军和模块进度；默认收基础放置与施工总材料的 30%（不含升级和修复投资），另扣当前经验的 30%，逐项向上取整，定义可调。非法位置、取消、资金不足不扣款。施工/修复/荒废不可移动，远征在途限制移动和升级。

道路可拖动或点起止位置，形成直线/L 形路径；两种 L 形选择非法格较少的一种。既有正常道路不重复付费；任一新格非法整段拒绝，不是自动绕障碍工具。

选中建筑默认显示蓝色道路加权行动力可达格、紫色 Buff 配置范围、绿色实际提供点及连续资源路径。底部“移动力”对应现有 ActionPower 资源连接预算，并非新增建筑移动次数。路径从与提供点选择相同的加权距离回溯；提供点按优先级、路径代价、稳定 ID 选择。详情不再展示连接候选列表，无法供给归入异常提示；付款仍来自全城正常库存，不要求物资恰好放在选中的仓库。经济、岗位和来源解释见 [经济与岗位](经济与岗位.md)。

## 荒废、修复与拆除

普通建筑耗尽生命进入荒废，立即停止功能并锁定来源库存。居民死亡、工人失业、库存删槽、驻军转待分配池在黎明统一提交；保留建筑身份、等级、朝向和皮肤。已出勤士兵不减血，尚在出勤队列的士兵以至多 50% 生命继续出勤。

修复无需工人。开始确认冻结总费和时长，白天逐期付费推进，余数分给较早回合；缺材料/断连整期暂停。优先用待存放，剩余部分需正常库存连接。默认修复为已付建造投资的 50%；可在“维护与修复”模块配置修复材料和默认修复回合数。修复费不增加建造投资。

修好恢复能力和生命，不自动招工或召回士兵，库存为空；住宅在该次黎明迁入 min(2,容量) 人，不提前参加当次生产/食谱/税收。

正常拆除返还已付建造投资 50%，荒废/修复中返还 20%，逐资源向上取整。施工仅计算已经支付的阶段；返还溢出直接损失，不进待存放。确认展示库存损失、返还、溢出与居民/工人/士兵/英雄/远征后果。

PlayerHome（王宫 / 皇宫）是核心，提供基础人口、库存、3 个通用驻兵槽、4 个通用任务承接槽及 1 个贸易邀约槽；被摧毁直接终局，不走普通废墟流程，UI 不显示耐久。


工人效率侧栏的档位在建筑资产“岗位与补贴 → 工作效率档位”中明确设置（等级、最少工人、最多工人）。UI 不从容量或效果门槛生成档位。配置和校验说明见 [建筑模块配置](../ECS/建筑模块配置.md#工作效率档位)，侧栏规则见 [经济与岗位](经济与岗位.md#工人档位侧栏)。

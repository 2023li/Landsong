# 内容制作指南

运输工人是由资源供给连接调度的平民，见[运输工人制作与接入](昼夜与战斗系统/运输工人制作与接入.md)：男女模型共用一个固定动画器，白天往返，入夜回家，死亡扣人口。

本页是新增内容的操作入口。详细步骤分别维护在下面的手册中；菜单、字段和产物目录以这些手册及当前代码为准。

| 要做什么 | 打开哪份说明 | 起始入口 |
| --- | --- | --- |
| 创建一座建筑，配置已有功能和各等级模型 | [建筑创建流程](ECS/建筑玩法与制作工作流.md) | Landsong → 内容制作 → 创建建筑 |
| 创建士兵、英雄或敌人，生成动画及预制体 | [单位创建流程](昼夜与战斗系统/单位制作流程.md) | Landsong → 内容制作 → 创建单位 |
| 创建科技节点，配置前置与建筑蓝图等奖励 | [科技创建流程](科技系统/README.md) | Project 右键 → Create → Landsong → Definitions → Research → Technology |
| 给建筑增加现有模块不支持的新玩法 | [新增建筑能力开发流程](ECS/新增建筑能力开发流程.md) | 按逐文件职责表添加配置、编译、运行和必要的请求/存档代码 |

建筑手册以“二级科研小屋”为例，说明 ID、占地、科研产出、等级模型和蓝图如何配置。单位手册以“基础动作哨兵”为例，给出可复用的模型、七个动作及着色器位置，并说明装备切换分支。

## 开始制作前

1. 保存需要保留的编辑内容，退出 Play，等待脚本编译和资源导入结束。
2. 确定稳定 ID 与显示名称。例如 `building.research_hut` 和“科研小屋”；ID 用于内容身份，显示名称用于玩家界面。创建器要求 ID 以字母或数字开头，只含字母、数字、下划线、点、连字符；ID 和名称均不超过 120 个 UTF-8 字节。
3. 查看制作 Inspector 顶部的“正式内容集”。它来自 `Assets/Landsong/ECSContent/World/GameWorldTemplate.prefab` 的内容集引用，工具会沿同一引用注册和校验。创建器不要求手工修改各个目录的注册数组。
4. 新增内容使用未占用的 ID。创建后保持 ID 与 Unity `.meta` GUID 稳定；显示名可以按需要修改。

## 每次制作的完成顺序

创建资产 → 配置玩法与模型 → 配置获得/出现途径 → 保存 → 编译显示目录 → 校验 → 在新测试会话中体验。

| 操作 | 作用 |
| --- | --- |
| Landsong → ECS → Compile domain display catalogs | 同步图标、说明、显示名称和科技树布局等显示数据 |
| Landsong → 内容制作 → 校验正式制作内容 | 检查领域配置、显示同步及预制体制作结构 |
| Landsong → ECS → Verification → Content authoring workflow | 验证创建工具、重复执行、失败清理和报告列出的运行行为 |
| 图形 Play 中体验新增内容 | 确认真实获得途径、画面、动画、操作和生命周期符合设计 |

新增或修改玩法内容后，用新测试会话验收；已有存档仍受内容指纹及版本校验约束。完整检查按 [验证工作流](ECS/验证工作流.md) 执行。

## 创建以后修改哪里

| 修改内容 | 修改位置 |
| --- | --- |
| 建筑数值、功能、占地、最高等级 | 生成的 Building 定义资产 |
| 建筑模型、等级、皮肤或施工外观 | 建筑完整根 Prefab 的对应槽位；随后补齐接线 |
| 单位战斗数值、费用、成长 | 生成的 Soldier / Hero / Enemy 定义资产 |
| 单位 AI 配置或 View 引用 | 生成的逻辑 Prefab |
| 单位模型、装备挂点和材质 | 生成的 View Prefab 及本单位 Materials |
| 单位状态切换和具体动作 | 生成的 Controller 与 Clips；保持手册中的参数契约 |

创建按钮用于首次生成。重复相同 ID 会验证并打开已有产物，不把配方重新覆盖到资产；调整已建单位时直接编辑对应产物。各手册中的示例名称、ID 和数值仅供演练，文档不会自动将它们加入正式游戏内容。

单位实例：[狼敌人制作与接入](昼夜与战斗系统/狼敌人制作与接入.md)，包含固定资源目录、动画结构、战斗配置和普通夜敌军池接入位置。
